The code for the paper Backstepping-Guided Reinforcement Learning for Wide-Range Saint-Venant Canal Regulation.

Preliminary Our demonstration code is based on Python 3.11 and utilizes several key third-party libraries, including
PyTorch 2.7.1 SciPy 1.14.1 pandas 2.2.3 DeepXDE 1.13.2 Gym version 0.29.1 Numpy version 2.2.4 Stable Baselines3 version 2.2.1 

Code Description :
"deeponet training": Used for dataset generation and training the DeepONet model. 
"RL training": Used for reinforcement learning training. 
"test": Used to store all images generated during the program execution. 
"cac_saint_venant_env_no_bs": It includes rewards and environments.
